# 🤖 tutor-bot

Telegram-бот для репетитора: запись учеников, расписание, домашние задания,
оплаты, отзывы, рассылки, реферальная программа и аналитика — в одном месте.

Стек: **Python 3.11+ · aiogram 3 · SQLite (aiosqlite, WAL) · APScheduler · Telethon**

---

## ✨ Возможности

| Для ученика | Для репетитора (админ-панель `/admin`) |
|---|---|
| Запись на пробное и обычные занятия | Управление учениками, предметами, слотами |
| «📋 Мои занятия» с напоминаниями за 60 и 15 мин | Повторяющиеся слоты (автогенерация на 2 недели) |
| Домашние задания с файлами и сдачей | ДЗ: выдача, проверка, оценки, фидбек |
| Счета и кнопка «✅ Я оплатил» | Подтверждение оплат, напоминания о долгах |
| Отзывы, реферальная скидка | Рассылки (от бота и userbot), DND-режим, аналитика |

## 🚀 Быстрый старт

```bash
git clone https://github.com/gidro783-ops/tutor-bot.git
cd tutor-bot

python -m venv venv && source venv/bin/activate
pip install -r requirements.txt        # или: make install

cp .env.example .env                   # заполните: токен, ID, пароль, ключ шифрования
python main.py                         # или: make run
```

Ключ шифрования генерируется так:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Пароль админки рекомендуется хранить хэшем (`ADMIN_PASSWORD_HASH`):
```bash
python -c "from utils.security import hash_password; print(hash_password('ВАШ_ПАРОЛЬ'))"
```

## 🤖 ИИ-ассистент (отвечает ученикам от лица репетитора)

Никакого «обучения» не нужно: в админке (/admin → 🤖 ИИ-ассистент)
заполняется анкета — имя, предметы и цены, опыт и формат. Она вместе
с вашим FAQ попадает в системный промпт, и ИИ отвечает **только по
этой информации**, ничего не выдумывая и не признаваясь, что он ИИ.

Два режима работы:

- **В боте** — ученик жмёт «🤖 Спросить» в меню и общается
  с ассистентом (кнопки меню работают, выход — «⏹ Выйти» или /cancel).
- **✉️ В личных сообщениях аккаунта репетитора** (нужен подключённый
  userbot): ИИ отвечает всем, кто написал вам в ЛС, от вашего имени.
  Защита от неловких ситуаций:
  - 🚫 **список исключений** — друзьям, родным и кому угодно ИИ не
    отвечает (админка → 🤖 ИИ-ассистент → 🚫 Исключения, добавление
    по @username);
  - если вы ответили человеку **сами** — ИИ молчит у него 24 часа;
  - кулдаун 60 секунд между автоответами одному человеку;
  - боты, команды и группы игнорируются.

Лимиты: Free — 10 ответов ИИ в день (общие для бота и ЛС),
PRO — безлимит. Работает с любым OpenAI-совместимым API:

```
AI_API_KEY=ваш_ключ
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
```

## 🚀 10 новых функций (v12)

1. **🧠 Свой промпт ИИ** — полная инструкция нейросети своими словами
   (/admin → 🤖 ИИ-ассистент → «Свой промпт»). Главнее стиля; анкета
   с ценами прикрепляется автоматически.
2. **📤 Шаблоны ответов** — частые сообщения ученикам в 1 клик
   (с подстановкой {name}). ⚙️ Ещё → Шаблоны.
3. **⏰ Отложенные сообщения** — «отправить через 2ч» или в точное время.
4. **📂 Материалы** — файлы для учеников (конспекты, пособия):
   загрузка в ⚙️ Ещё, у учеников своя кнопка в меню.
5. **📊 Мой прогресс** — ученик видит занятия, часы, сданные ДЗ и
   средний балл (Профиль → Мой прогресс).
6. **⭐ Авто-отзыв** — после окончания занятия бот сам просит ученика
   оценить его (и помечает занятие завершённым).
7. **🌙 Тихие часы ИИ** — ночью автоответы в ЛС не уходят
   (`AI_DND_START`/`AI_DND_END`, по умолчанию 23:00–08:00).
8. **📄 Отчёт по ученику** — карточка одним файлом (кнопка в ученике).
9. **📅 «Завтрашние занятия»** — сводка репетитору каждый вечер в 20:00.
10. **📈 Итоги недели** — по понедельникам в 9:00: оплата, новые
    ученики, сданные ДЗ.

Главное меню админки сокращено до 10 кнопок — редкое убрано в «⚙️ Ещё».

## 🧭 Удобства навигации

- Команда **/cancel** (или слово «отмена», или кнопка «❌ Отмена»)
  прерывает любой ввод — пароль, номер телефона, код, текст рассылки.
- Из любого шага ввода всегда есть кнопка «◀️ Назад (отменить ввод)»
  под сообщением.
- **Служебные сообщения удаляются сами** через 3 минуты (запросы кодов,
  подсказки ввода, «✅ сохранено») — чат не засоряется. Настройка:
  `MESSAGE_TTL_MINUTES` в `.env`, `0` = выключить. Содержимое
  (ответы ИИ, списки занятий, счета) не удаляется.
- **Дедлайн ДЗ**: ежедневно в 11:30 (`HW_REMINDER_HOUR`) ученики
  получают напоминание «сдать завтра» по невыполненным заданиям.
- Напоминания о занятиях работают и для занятий **после полуночи**
  (раньше окно «за 60/15 минут» через полночь игнорировалось).

## 🗄 Автобэкап базы

Каждую ночь (по умолчанию 03:30, настраивается `BACKUP_HOUR`/`BACKUP_MINUTE`)
бот делает снапшот SQLite через `VACUUM INTO`, хранит последние 14 копий
(`BACKUP_KEEP`) в `data/backups/` и присылает файл админам в Telegram.
На Heroku это критично — файловая система dyno эфемерна.

Ручной бэкап: `make backup`

## 🔒 Безопасность

- Все секреты — только в `.env` (в git не попадает, см. `.gitignore`).
- `*.session` (Telethon) полностью исключены из git — этот файл даёт
  полный доступ к аккаунту.
- Пароль админки: bcrypt-хэш + rate-limit (5 попыток → блок на 15 мин).
- ⚠️ Userbot-рассылки от вашего имени нарушают Telegram ToS и ведут к бану
  аккаунта — используйте рассылку от бота.

## ☁️ Деплой

### Railway (рекомендуется, с Volume)

Персистентное хранилище из коробки: `railway.toml` и `.python-version` уже в репо.
Пошагово — **[docs/RAILWAY.md](docs/RAILWAY.md)**: монтируется Volume в `/data`,
туда уходят база, бэкапы и Telethon-сессия (`DATABASE_PATH=/data/tutor_bot.db`,
`USERBOT_SESSION_PATH=/data/tutor_userbot_session`). Данные переживают передеплои.

### Heroku

`Procfile` и healthcheck-сервер уже на месте. Версия Python — в `runtime.txt`.

```bash
heroku config:set BOT_TOKEN=... ADMIN_IDS=... ADMIN_PASSWORD_HASH=... ENCRYPTION_KEY=...
git push heroku main
```

⚠️ У Heroku файловая система эфемерна — спасает ежедневный бэкап в Telegram
(`services/backup.py`), но Volume Railway надёжнее.
